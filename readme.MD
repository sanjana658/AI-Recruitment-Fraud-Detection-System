# AI Recruitment Fraud Detection System

## Overview

The AI Recruitment Fraud Detection System is a Machine Learning and NLP-based application designed to identify potentially fraudulent job postings.

The system analyzes job descriptions, detects suspicious patterns, calculates fraud risk scores, and provides explainable results through an interactive Streamlit dashboard.

## Problem Statement

Online job portals contain both legitimate and fraudulent job postings. Many fake postings attempt to scam job seekers through registration fees, unrealistic salaries, and misleading offers.

This project aims to assist users in identifying suspicious job opportunities before applying.

## Features

* Fake Job Detection using Machine Learning
* TF-IDF Text Vectorization
* Fraud Risk Score
* Safety Score
* Suspicious Keyword Detection
* Explainable AI
* Historical Analysis Tracking
* Interactive Streamlit Dashboard

## Technologies Used

* Python
* Pandas
* Scikit-Learn
* Streamlit
* TF-IDF Vectorization
* Logistic Regression
* Random Forest (Model Comparison)

## Dataset

Fraudulent Job Postings Dataset from Kaggle.

## Results

* Accuracy: 96.78%
* Recall for Fraudulent Jobs: 90%
* Interactive Dashboard for Real-Time Analysis
